Notes for developers:
  - This model uses KHR_draco_mesh_compression. drei's useGLTF
    (@react-three/drei >= 9) automatically configures the Draco decoder
    from the gstatic CDN, so no extra setup is needed when loading via
    useGLTF. If loading with a raw THREE.GLTFLoader, set up a
    DRACOLoader and point it at https://www.gstatic.com/draco/v1/decoders/.
  - Textures use the EXT_texture_webp extension (supported by three.js
    since r137; this project uses r169).
  - The model is normalized at runtime in GlbPhone.tsx: it is recentered
    on the origin and scaled so its largest dimension is 3.0 units.
  - The previous procedurally-generated CC0 phone was backed up to
    phone.glb.bak.procedural.
